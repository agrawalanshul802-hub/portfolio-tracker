1. Introduction and Objectives

1.1 Introduction:

In today’s fast-evolving financial landscape, Indian retail investors diversify their wealth across multiple asset classes including Indian equities (NSE & BSE), mutual funds, exchange-traded funds (ETFs), sovereign gold bonds, and cryptocurrencies. However, tracking assets across disparate brokerage platforms such as Zerodha, Groww, AngelOne, and Upstox leads to fragmented data, tedious manual spreadsheet tracking, and security vulnerabilities associated with sharing broker API credentials.

Portfolio Tracker is a secure, privacy-first, cloud-synchronized web application designed to solve these challenges. Built with a lightweight Python Flask backend, modern Supabase PostgreSQL cloud database, and high-performance Chart.js visual analytics, the platform enables investors to track holdings, compute real-time profit & loss (P&L), analyze asset class distribution, monitor financial news, query an AI portfolio analyst, and export formal valuation statements — all without surrendering broker passwords or Demat credentials.

The system is fully deployed on Render Cloud at https://portfolio-tracker-1-n2qq.onrender.com and is accessible from any device worldwide. With over 2,947 lines of Python backend code and a 3,500+ line frontend, the system represents a complete, production-quality full-stack software engineering project demonstrating mastery of Flask, REST API design, OAuth 2.0, PostgreSQL, concurrent threading, AI API integration, and responsive UI development.

1.2 Objectives of the System:

  1. Centralized Multi-Asset Tracking: Single unified dashboard for Equities, ETFs, Mutual Funds, Gold, Crypto, and Custom assets in Indian Rupees (INR ₹).
  2. Real-Time Price Synchronization: Live financial data feeds (NSE/BSE) using asynchronous multi-threaded caching engines with 45-second TTL.
  3. Privacy-First Architecture: Eliminate credential exposure by allowing manual or CSV-based asset addition without linking broker login APIs.
  4. Cloud Data Persistence: Secure PostgreSQL storage on Supabase Cloud with PBKDF2-SHA256 password hashing and cryptographic salt (100,000 iterations).
  5. Comprehensive Visual Analytics: Dynamic Chart.js donut charts, sector breakdowns, and portfolio health scores.
  6. Automated Statement Generation: One-click export of PDF valuation reports and CSV audit records for tax filing.
  7. AI Market Assistance: AI Portfolio Analyst (Groq/Gemini/OpenRouter) capable of answering stock queries, risk evaluations, and market news summaries.
  8. IPO Intelligence Module: Track live and upcoming IPOs with real-time Grey Market Premium (GMP) from NSE, Groww, and IPOWatch APIs.
  9. News Aggregation Engine: Fetch and match financial news from Moneycontrol RSS and Yahoo Finance to user’s specific holdings.

3. System Features and Modules

3.1 Core System Features:

  • Real-Time Net Worth Valuation: Instant computation of invested capital, market value, total unrealized gain, and day return using multi-threaded price workers.
  • In-Memory Multi-Worker Price Caching: 45-second high-speed cache with ThreadPoolExecutor (up to 20 workers) eliminating outbound latency and preventing API rate limiting.
  • Multi-Asset Support: Manages Indian Equities (NSE/BSE) and MCX Commodities (Gold, Silver, Crude Oil, Natural Gas) holdings in one unified table with INR valuation.
  • Partial Sell with Weighted Average Cost: Records partial sell transactions with automatic recalculation of average cost basis for remaining shares.
  • Interactive Valuation Reports: Modal generator with live KPIs, holding tables, and one-click PDF printing / CSV download for tax audit trails.
  • IPO Tracker with Live GMP: Aggregates Open, Upcoming, and Recently Listed IPOs from NSE, Groww, and IPOWatch with real-time Grey Market Premium data.
  • AI Portfolio Analyst Chat: Conversational AI with quick-question shortcuts, markdown rendering, and session-aware portfolio context injection.
