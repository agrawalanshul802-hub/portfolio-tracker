1. Introduction and Objectives

Introduction:

In today's fast-evolving financial landscape, Indian retail investors diversify their wealth across multiple asset classes including Indian equities (NSE & BSE), mutual funds, exchange-traded funds (ETFs), sovereign gold bonds, and cryptocurrencies. However, tracking assets across disparate brokerage platforms (e.g., Zerodha, Groww, AngelOne, Upstox) leads to fragmented data, tedious manual tracking on spreadsheets, and security vulnerabilities associated with sharing broker API credentials.

Portfolio Tracker is a secure, privacy-first, cloud-synchronized web application designed to solve these challenges. Built with a lightweight Python Flask backend, modern Supabase PostgreSQL database, and high-performance Chart.js visual analytics, the platform enables investors to track their holdings, compute real-time profit & loss (P&L), analyze asset class distribution, monitor market news, query an AI portfolio analyst, and export formal valuation statements without ever surrendering broker passwords.

Objectives:

The primary objectives of the Portfolio Tracker system are:

  1. Centralized Multi-Asset Tracking: Provide a single unified dashboard to track equities, ETFs, mutual funds, gold, and custom assets in Indian Rupees (INR).
  2. Real-Time Price Synchronization: Integrate low-latency live financial data feeds (NSE/BSE) using asynchronous multi-threaded caching engines.
  3. Privacy-First Architecture: Eliminate credential exposure by allowing manual/CSV asset addition without linking sensitive broker login APIs.
  4. Cloud Data Persistence: Implement secure PostgreSQL storage on Supabase Cloud with PBKDF2-SHA256 password hashing.
  5. Comprehensive Visual Analytics: Generate interactive dynamic Chart.js donut charts, sector breakdowns, and portfolio health scores.
  6. Automated Statement Generation: Enable one-click export of PDF valuation reports and CSV audit records for tax and financial review.
  7. AI Market Assistance: Embed an AI Portfolio Analyst capable of answering stock queries, risk diversification evaluations, and market news summaries.

3. System Features and Modules

Core System Features:

  • Real-Time Net Worth Valuation: Instant automated computation of invested capital, market value, total unrealized gain, and day return.
  • In-Memory Multi-Worker Price Caching: 45-second high-speed cache eliminating outbound latency and preventing rate limiting.
  • Multi-Asset Support: Seamlessly manages Equities, ETFs, Mutual Funds, Bonds, Gold, and Crypto.
  • Interactive Valuation Reports: Modal generator offering live KPIs, holding tables, and one-click PDF printing / CSV download.

Detailed Module Description:

1) Authentication & User Account Module:
Handles user registration, login, session cookies, and Google OAuth 2.0 callback processing. Passwords are encrypted using salted PBKDF2 hashing. Includes security question recovery and user profile modals.

2) Holdings Management (CRUD) Module:
Empowers users to add new holdings (Symbol, Exchange, Name, Buy Price, Quantity), edit existing allocations, record partial sell transactions, or delete holdings. Changes are automatically synced with Supabase PostgreSQL.

3) Real-Time Price Polling Engine:
Fetches live stock prices for NSE/BSE tickers using parallel multi-threaded workers (`ThreadPoolExecutor`) with aggressive timeouts (2.5s) and automatic candidate symbol matching.

4) Analytics & Visual Intelligence Module:
Renders dynamic Chart.js donut charts displaying asset weights, portfolio health scores, and top concentration risks.

5) AI Assistant & News Intelligence Module:
Provides a conversational interface for asking stock analysis questions, integrated with live RSS financial news streams and IPO tracking data.

# Initialize Supabase Cloud Client SUPABASE_URL = os.environ.get('SUPABASE_URL', 'https://your-project.supabase.co') SUPABASE_KEY = os.environ.get('SUPABASE_KEY', 'sb_secret_your_secret_key_here') supabase: Client = create_client(SUPABASE_URL, SUPABASE_KEY) # Server-Side In-Memory 45s Price Cache LIVE_PRICE_CACHE = {} CACHE_LOCK = threading.Lock() CACHE_TTL = 45.0 # seconds def fetch_single_quote(symbol): candidates = [symbol] if '.' not in symbol and not symbol.endswith(('.NS', '.BO')): candidates = [symbol + '.NS', symbol + '.BO', symbol] for target in candidates: try: url = f'https://query1.finance.yahoo.com/v8/finance/chart/{urllib.parse.quote(target)}?range=1d&interval=1m' req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)'}) with urllib.request.urlopen(req, timeout=2.5) as res: data = json.loads(res.read().decode('utf-8')) meta = data.get('chart', {}).get('result', [{}])[0].get('meta', {}) price = meta.get('regularMarketPrice') if price and float(price) > 0: return float(price) except Exception: continue return None

7.2 Multi-Threaded Price Resolution Endpoint:

@app.route('/api/live-prices', methods=['POST']) def get_live_prices(): req_data = request.get_json(silent=True) or {} symbols = req_data.get('symbols', []) now = time.time() results = {} missing_symbols = [] with CACHE_LOCK: for sym in symbols: s_clean = sym.strip().upper() if s_clean in LIVE_PRICE_CACHE and (now - LIVE_PRICE_CACHE[s_clean]['timestamp']) < CACHE_TTL: results[s_clean] = LIVE_PRICE_CACHE[s_clean]['price'] else: missing_symbols.append(s_clean) if missing_symbols: with concurrent.futures.ThreadPoolExecutor(max_workers=min(20, len(missing_symbols) or 1)) as executor: future_to_sym = {executor.submit(fetch_single_quote, s): s for s in missing_symbols} for future in concurrent.futures.as_completed(future_to_sym): s = future_to_sym[future] p = future.result() if p is not None: results[s] = p with CACHE_LOCK: LIVE_PRICE_CACHE[s] = {'price': p, 'timestamp': now} return jsonify({'success': True, 'prices': results})
