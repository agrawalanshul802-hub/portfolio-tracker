Section 1

Project Synopsis (Project Proposal)

A comprehensive overview of the project objectives, problem statement, proposed solution, and scope.

1.1 Problem Statement

Individual investors in India lack a unified, free, and intelligent platform to track stock and cryptocurrency holdings in real-time. Existing platforms like Groww and Zerodha are broker-locked -- they only show holdings purchased through their own service. An investor with accounts across multiple brokers has no single dashboard to see their total net worth, overall profit/loss, and allocation breakdown.

1.2 Proposed Solution

A full-stack web application that allows users to:

  • Register/Login securely (email+password or Google OAuth 2.0).
  • Add holdings from any Indian stock exchange (NSE/BSE) or cryptocurrency.
  • Track live prices via Yahoo Finance API integration.
  • View analytics -- allocation pie charts, sector distribution, and performance metrics.
  • Ask AI -- an AI-powered portfolio analyst (Gemini/Grok) that answers questions about diversification, risk, and performance.
  • Read curated news -- aggregated from Moneycontrol RSS and Yahoo Finance, matched to the user's specific holdings.

1.4 Objectives

  1. Build a responsive, premium-quality single-page web application.
  2. Implement secure authentication with PBKDF2 password hashing and Google OAuth 2.0.
  3. Provide real-time market data via a CORS-bypass proxy to Yahoo Finance.
  4. Deliver intelligent portfolio insights using AI (Gemini API) with a local fallback analyzer.
  5. Aggregate and display portfolio-relevant news from multiple sources.

Design Justifications

DecisionRationale
No prices tablePrices fetched in real-time from Yahoo Finance every 60s. Historical storage would require background schedulers and gigabytes of data.
No sessions tableFlask uses cryptographically signed cookies. Session data stored in cookie itself (HMAC-SHA256 signed).
Composite PK (id, user_email)Each UUID unique per user. ON DELETE CASCADE auto-removes orphaned holdings.
Separate yahooSymbol columnYahoo uses different format (RELIANCE.NS) than NSE tickers (RELIANCE). Avoids repeated concatenation.
